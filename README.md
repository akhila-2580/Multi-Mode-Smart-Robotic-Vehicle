# Multi Mode Smart Robotic Vehicle

## Project Description

The Multi Mode Smart Robotic Vehicle is an Arduino-based robotic system designed to provide multiple control and navigation modes. The vehicle combines manual control, voice control, tilt-based control, obstacle avoidance, and human-following functionality.

The system uses an Arduino microcontroller, Bluetooth communication, ultrasonic sensing, motor control, and a mobile application to achieve flexible and intelligent robotic navigation.

## Features

- Manual Mode
- Voice Control
- Tilt Control
- Obstacle Avoidance
- Human Following
- Bluetooth Communication
- Android Application
- Autonomous Navigation

## Operating Modes

### Manual Mode

The robot can be controlled manually using the mobile application.

### Voice Control

The vehicle can receive voice commands through the mobile application.

### Tilt Mode

The robot can be controlled by tilting the smartphone in different directions.

### Obstacle Avoidance

The ultrasonic sensor detects obstacles and helps the robot avoid collisions.

### Human Following

The robotic vehicle is designed to follow a person using its sensing system.
